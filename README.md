# CEO Finder - Clean Build

Quick start:

1. Unzip project.
2. `git init` (or add to your repo), push to GitHub.
3. Deploy to Render (connect repo) or manual deploy the ZIP.

Usage:
- /upload_db to upload database files (each database block: CEO name line, next line contains an email with domain)
- / to upload a file to process (will insert CEO names above matching domains)
